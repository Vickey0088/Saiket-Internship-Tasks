# Frontend Development Tasks – Saiket Systems

This repository contains a collection of frontend development tasks completed during my time at **Saiket Systems** as a **Frontend Web Developer Intern**. These tasks cover a variety of fundamental to intermediate web development skills using **HTML**, **CSS**, and **JavaScript**.

---

## 📁 Task Overview

### ✅ Task 1: Basic Blog Post Layout
- **Description**: Created a semantic HTML structure for a blog post.
- **Features**: Title, publication date, author, introduction, content list, conclusion, image, and a "Read More" link.
- **Skills**: HTML

---

### ✅ Task 2: Styling a Product Card
- **Description**: Designed a clean product card UI.
- **Features**: Product image, name, price, and an "Add to Cart" button with hover effects.
- **Skills**: HTML, CSS

---

### ✅ Task 3: Responsive Webpage Layout
- **Description**: Built a layout with header, sidebar, main content, and footer.
- **Features**: Responsive design using media queries; grid for desktops and stacked layout for mobile.
- **Skills**: HTML, CSS

---

### ✅ Task 4: Simple Quiz Application
- **Description**: Developed an interactive quiz with JavaScript.
- **Features**: At least 3 MCQs, next question navigation, score display, and validation to prevent skipping.
- **Skills**: JavaScript, DOM Manipulation

---

### ✅ Task 5: To-Do List App
- **Description**: Created a to-do list with full CRUD operations.
- **Features**: Add, edit, delete, complete tasks with responsive design.
- **Skills**: HTML, CSS, JavaScript

---

### ✅ Task 6: Webpage Clone (Real-world Simulation)
- **Description**: Cloned a real-world landing page layout.
- **Features**: Recreated layout and styling, added dynamic interactivity using JavaScript.
- **Skills**: HTML, CSS, JavaScript

---

## 🚀 Skills Demonstrated
- Semantic HTML
- Responsive CSS (Flexbox, Grid, Media Queries)
- JavaScript (DOM Manipulation, Events)
- UI/UX Design Principles
- Real-world project simulation
